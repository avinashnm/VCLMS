### 6.X Global Catalog and Inventory Management (HOD)
Before utilizing the No-Code Experiment Builder, the Admin must establish the foundational scientific realities of the digital laboratory. This is achieved through the **Manage Catalogs & Reactions** interface, a sophisticated global inventory system that dictates exactly which resources are available for simulation authoring. This module is divided into three distinct organizational tabs:

#### 6.X.1 The Global Chemical Inventory
The Global Chemical Inventory functions as the absolute master repository for all reagents, analytes, and indicators utilized across the institutional environment. It securely catalogs standard chemical nomenclature alongside specific molecular formulas to prevent input redundancies during experiment setups. Furthermore, it permanently registers precise physical properties, such as baseline molarity (e.g., 0.1M) and fluid densities, which the backend utilizes to strictly evaluate the student’s mathematical derivations. Crucially, this interface directly ties chemicals to specific rendering metadata, defining default visual states utilizing standard screen Hex codes (e.g., `#FFA500B0` for Methyl Orange). This ensures seamless, physically accurate color morphing across all simulated experiments regardless of which faculty member authors them.

#### 6.X.2 The Digital Apparatus Registry
The Digital Apparatus Registry meticulously manages the structural and geometric inventory of the simulated laboratory, providing standard physical items such as 50mL Burettes and 250mL Conical Flasks. By cataloging precise, predefined coordinate boundaries and collision layers, this module acts as the physical blueprint directly parsed by the `p5.js` rendering engine. It actively secures volumetric capacity limits, ensuring that the engine mathematically recognizes exact overflow points to enforce strict procedural realism. Locking these absolute dimensions at the global administrative level guarantees that students consistently encounter highly standardized UI interactions. This uniformity effortlessly mimics the stringent standardization protocols of a professional, physical chemistry stockroom.

#### 6.X.3 Master Reaction Logic Configuration
The Master Reaction Logic module establishes the immutable, deeply mathematical core of the simulation environment by globally defining exactly what happens when specific inventory items interact. Rather than forcing faculty to redundantly hardcode physical behaviors for every new experiment, this catalog dictates absolute, universal endpoint triggers—such as the exact pH shift required for a Phenolphthalein indicator to render a target pink visualization. These overarching stoichiometric rules act as the absolute source of truth for the entire platform. Consequently, when an administrator rapidly authors a custom titration scenario utilizing the No-Code builder, the engine securely inherits these flawless global reactions without requiring independent source code validation.
